# Kin logo

The mark is one ring (an entity) around three linked wallets: Kin caps the ring, not each wallet.

| File | Use |
|---|---|
| `kin-logo-on-light.svg` / `.png` | Logo with wordmark, for light backgrounds |
| `kin-logo-on-dark.svg` / `.png` | Logo with wordmark, for dark backgrounds |
| `kin-mark.svg`, `kin-mark-512.png` | Mark alone (avatar, social profile, app icon), blue `#2f55e4` |
| `kin-mark-on-dark.svg` | Mark alone for dark backgrounds, blue `#7d97ff` |
| `favicon.svg` | Browser icon; switches blue in dark mode (also `web/app/icon.svg`) |

Colours: blue `#2f55e4` (dark mode `#7d97ff`), ink `#17171b` (dark mode `#ececf1`). The wordmark is drawn as
strokes, not set in a font, so it looks the same everywhere.
